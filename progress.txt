# Progress Log

## Learnings (from previous sessions)

- EDATE DAX function was not in unconvertible list, causing invalid MDX to be generated
- AtScale MDX does not have an EDATE equivalent for measure expressions
- DAX uses "N/A" strings as null indicators; MDX uses NULL - need to transform comparisons
- AtScale MDX is stricter than standard MDX - test deployments early
- DAX filter context modifications (ALL, column filters) don't translate to MDX
- Type consistency is critical - MDX IIF requires same type in both branches
- Fallback to TODO stub is safer than producing invalid MDX
- DAX BLANK() in nested expressions needs toMdx() handling → NULL
- DAX & operator for string concat → MDX + operator
- BIM measures with sourceColumn but no DAX expression need to be created as base metrics when referenced

## Iteration 1 - US-001: Pre-populate measTables for correct table classification
- **Problem**: Tables with BIM measures but on "right" side of relationships were incorrectly classified as dimension-only tables
- **Root cause**: `populateTableLists()` classified tables before measure conversion ran, so `measTables` was empty
- **Fix**: Added `prePopulateMeasTables()` method to scan BIM tables for measures BEFORE table classification
- **Files changed**:
  - `src/commands/bim-to-sml/bim-converter/table-converter.ts` - Added `prePopulateMeasTables()` method
  - `src/commands/bim-to-sml/bim-converter/bim-to-sml-converter.ts` - Call `prePopulateMeasTables()` before `populateTableLists()`
- **Learnings for future iterations**:
  - Table classification depends on `measTables` to know which tables have measures
  - Order of operations matters: table classification must run AFTER measTables is populated
  - Tables can be in BOTH factTables and dimTables (if they have measures AND are on "right" side)
  - The `isDimensionOnlyTable()` check returns true only if table is in dimTables but NOT in factTables
- **Verified**:
  - FactPolicyLine_bim.json now shows "Fact Policy Line" in factTables
  - Marketing_-_Advertising_bim.json conversion works
  - RetailPolicyLine_bim.json conversion works
  - npm run test-custom-calcs passes
