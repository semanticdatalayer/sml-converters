## Session: Fix mol.bim.json deployment errors

**Initial Error:** "Error getting physical type of flat attribute [Last transaction (base)]: Calculated measure Last transaction (base) is not valid: end of input expected"

**Root cause:** EDATE([Measures].[Last transaction],-12) is invalid MDX - EDATE is not a supported AtScale function

**Fix:** Add EDATE to unconvertible functions list in function-mappings.json
